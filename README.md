# Silicon Index

Apple SiliconのCPU・GPUコア、メモリ構成、ベンチマークを一覧で比較する静的サイトです。

- Mac向けMシリーズ全世代とA18 Pro以降の確認済み構成（iPad専用構成は除外）
- 1コア＝1つの四角でCPU / GPUを可視化。CPUはS / P / Eを色分け
- 世代・シリーズ・搭載製品で検索、コア数・メモリ・スコアで並べ替え
- CPUシングル・マルチ、GPU Metalのスコアと基準構成に対する倍率
- スマートフォン向けカード表示、ライト / ダーク表示
- 各構成にApple公式仕様とGeekbenchの出典

## GitHub Pagesで公開

Settings → Pages → Build and deployment で次を設定してください。

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

SaveするとGitHub Pagesの配信が始まります。公開前のURLは動作確認済みではありません。

## データと制約

データ確認日は2026年9月4日。23チップ・47構成。ベンチマークのCPU参考値は43構成に対応し、未確認値はnullです。自動更新ではありません。

Geekbench公式チャートの説明は7ですが、同じ値が機種詳細の説明では6と記載されていました。この不一致をサイト内に明記し、同時点の公式チャート内での参考比較としています。厳密な同一バージョン・同一条件の比較は未検証です。推定スコアは使いません。GPU構成を分離できない集計はCPU参考値のみです。

メモリの選択肢は製品ごとに異なることがあるため、詳細に条件を記載しています。iPhoneのRAM容量はApple製品仕様に記載がないため容量非公表としています。M3 Ultraの512GBは発売当初の構成として区別しています。

## 更新

`data.json`が構成データ、`template.html`が画面のテンプレートです。編集後は以下で`index.html`を再生成します。

```sh
python3 generate.py
```

公開に必要なのは`index.html`と`.nojekyll`だけです。外部JavaScript・フォント・ビルドサービス・APIキーは不要です。

## 検証

データのコア数内訳、メモリ配列、値の欠損を確認済み。JavaScriptの構文検査と、DOMスタブを用いた表示・検索・フィルタ・並べ替え・倍率・基準変更・詳細生成の検査を実施。実ブラウザによるレイアウト検査は未実施です。
